# Karaokê Gospel Retrô (Etapa 1)
Requisitos: Node.js 20.19+ ou 22.12+ no Windows.
- Executar: dois cliques em `scripts\iniciar.bat` (ou `npm install` e `npm run iniciar`).
- Gerar instalador e versão portátil `.exe`: `npm run dist` (arquivos na pasta `release`).
Abre uma janela (tela cheia na segunda tela, se houver).
Janela única: engrenagem (canto inferior esquerdo) abre cadastro, fila, ranking e microfone. Etapa 4 parcial: microfone, calibração e pontuação automática (participação + ritmo). Afinação ainda não.
O carrossel usa músicas de EXEMPLO sem áudio; o cadastro real é a Etapa 2.
